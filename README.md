# Проект: проект интернет-магазина

## Описание: создание приложения, описывающего работу интернет-магазина

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/Online_shop``
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Запустите локальный сервер проекта ```django_online_shop``` http://127.0.0.1:8000/

3. Создано приложение ```catalog```, в котором активны прототипы страниц:
   - home.html (Приветственная страница)
   - main.html (Главная)
   - contacts.html (Страница контактов)
   - feedback.html (Форма обратной связи)
   - product_detail.html (Страница подробного описания товара)
   - product_form.html (Страница внесения нового товара)
   - product_list.html (Список всех товаров)

4. В рамках данной домашней работы 25 было сделано:
   - Все имеющиеся в приложении ```catalog``` контроллеры переведены с FBV на CBV.
   - Создано новое приложение ```blog```
   - Для приложения ```blog``` реализован CRUD с использованием CBV
   - Добавлен счётчик просмотров статей блока на станицу просмотра статьи
   - Добавлена фильтрация опубликованных статей - на странице списка блога показаны только опубликованные статьи
   - Создано перенаправление после редактирования статьи: после успешного редактирования записи пользователь перенаправляется на просмотр этой статьи
