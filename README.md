# Проект: проект интернет-магазина

## Описание: создание приложения, описывающего работу интернет-магазина

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/Online_shop``
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Запустите локальный сервер проекта ```django_online_shop``` http://127.0.0.1:8000/

3. Создано приложение ```catalog```, в котором активны прототипы страниц:
   - home.html (Приветственная страница)
   - main.html (Главная)
   - contacts.html (Страница контактов)
   - feedback.html (Форма обратной связи)
   - product_detail.html (Страница подробного описания товара)
   - product_form.html (Страница внесения нового товара или актуализации существующего)
   - product_list.html (Список всех товаров)
   - product_confirm_delete,html (Страница подтверждения удаления товара)

4. Создано приложение ```blog```, в котором активны прототипы страниц:
   - article_detail.html (Страница описания статьи блога)
   - article_form.html (Страница внесения новой статьи или актуализации существующей)
   - article_list.html (Список всех статей блога)
   - article_confirm_delete.html (Страница подтверждения удаления статьи)

5. Создано приложение ```users```, в котором активны прототипы страниц:
   - user_form.html (Страница регистрации пользователя)
   - login.html (Страница авторизации)

6. В рамках данной домашней работы 28 было сделано:
   - Добавлены кастомные права к модели продукта can_unpublish_product — может отменять публикацию продукта
   - Создана группу «Модератор продуктов» с правами:
     * Разрешение can_unpublish_product
     * Разрешение на удаление любого продукта
   - Реализовано решение, что редактирование продукта доступно только его владельцу
   - Реализовано решение, что удаление продукта доступно владельцу и модератору
