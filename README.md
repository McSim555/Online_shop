# Проект: проект интернет-магазина

## Описание: создание приложения, описывающего работу интернет-магазина

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/Online_shop``
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Запустите локальный сервер проекта ```django_online_shop``` http://127.0.0.1:8000/

3. Создано приложение ```catalog```, в котором активны прототипы страниц:
   - home.html (Главная)
   - contacts.html (Страница контактов)
   - feedback.html (Форма обратной связи)

4. В рамках данной домашней работы 23 было сделано:
   - Подключена СУБД PostgreSQL для работы в проекте
   - В приложении ```catalog``` созданы модели Product и Category
   - Применены миграции для новых моделей
   - Настроена работа с админкой
   - Через Django shell созданы новые объекты классов Product м Category, осуществлена фильтрация, обновление и удаление
   - Сформированы фикстуры для моделей Category и Product
   - Создана кастомная команда add_test_products
   - В контроллер отображения главной страницы добавлена выборка последних 5 созданных продуктов и их вывод в консоль
   - Создана модель для хранения контактных данных. Настроен вывод контактов, заполненных через админку, на страницу с контактами
